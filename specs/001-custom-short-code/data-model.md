# Data Model: Custom Short Codes

## Short URL

Represents a saved mapping from a unique short code to its original destination.

| Field | Type / shape | Constraints | Behavior |
|---|---|---|---|
| Code | String | Required, unique, maximum 32 characters; custom values must be 3–32 ASCII letters/digits/hyphens/underscores and not a reserved route name | Generated by the existing behavior when the request omits a code; otherwise stores the validated user-provided value. Code identity is case-sensitive. |
| OriginalUrl | Absolute HTTP or HTTPS URL | Required; existing maximum length is 2048 characters | Target of the redirect. |
| CreatedAt | UTC date/time | Set at creation | Preserved for generated and custom-code links. |
| Clicks | Integer | Starts at zero | Incremented once for each successful redirect. |

### Relationships and Lifecycle

- Each short URL has exactly one code and one original destination.
- The code is immutable after creation. Editing and removal are out of scope.
- A code can be created only once. The existing unique index remains the final
  consistency guard during concurrent create requests.
- No new entity, table, column, index, or migration is required.

## Create Request

The existing create request has a required destination URL and gains an optional,
nullable custom code. Missing or null code selects automatic generation. A supplied
empty, whitespace-only, malformed, reserved, or already-used code is rejected; it is
never silently replaced with a generated code.
